## Introducción

En general, los administradores de sistemas interactúan con el sistema a través de la CLI (Command Line Interface). Esto es así porque las interfaces gráficas suelen ser ineficientes. Por un lado, utilizan mayor espacio en disco y por otro suelen no permitir realizar la misma cantidad de acciones o personalizar las instrucciones como uno esperaría.

Los comandos son la forma que tenemos de pasarle instrucciones al sistema operativo (a través de la CLI) para que este realice lo que necesitamos. Para esto es fundamental conocer los comandos y cómo se componen.

## Sintaxis

Los comandos en Linux deben enunciarse de esta forma:

```bash
comando [opciones] [argumentos]
```

Nota: opciones y argumentos no siempre son obligatorios, depende del comando. Por ejemplo, `ls` y `pwd` funcionan solos, pero `cp`, `mv` o `chmod` necesitan argumentos.

Ej:

```bash
chmod u+x archivo.sh
```

Esto cambia los permisos del archivo para el usuario agregándole privilegios para ejecutar.

## Comandos de navegación

| Comando | Descripción |
| ------- | ----------- |
| `pwd` | Print Working Directory, muestra en dónde estamos parados dentro del Filesystem. |
| `cd` | Change Directory, nos permite cambiar de un directorio a otro. |
| `ls` | List, enumera archivos y directorios. |

## Comandos de encendido y apagado

| Comando | Descripción |
| ------- | ----------- |
| `shutdown` | Apaga el sistema de manera ordenada. Requiere permisos de administrador (`sudo`) y suele usarse con opciones o un horario. |
| `reboot` | Reinicia el sistema. Requiere permisos de administrador (`sudo`). |

## Comandos de disco

| Comando | Descripción |
| ------- | ----------- |
| `du` | Disk Usage, muestra el espacio consumido del directorio en donde estamos parados, sumando sus subdirectorios. Con la opción `-h` muestra tamaños legibles (KB, MB, GB). |
| `df` | Disk Free, muestra el espacio libre que tenemos en cada filesystem montado. También se usa con `-h`. |

## Comandos de archivos o directorios

| Comando | Descripción |
| ------- | ----------- |
| `mkdir` | Crea un directorio. |
| `rmdir` | Elimina un directorio vacío. |
| `touch` | Crea un archivo vacío. |
| `mv` | Mueve o renombra un archivo o directorio. |
| `cp` | Copia un archivo o directorio (para directorios requiere la opción `-r`). |
| `rm` | Elimina un archivo o directorio (para directorios requiere la opción `-r`). |
| `cat` | Muestra el contenido de un archivo. |
| `more` | Muestra el contenido de un archivo en páginas. |
| `less` | Muestra el contenido de un archivo en páginas navegables. |
| `head` | Muestra las primeras líneas de un archivo. |
| `tail` | Muestra las últimas líneas de un archivo. |

## Otros

| Comando | Descripción |
| ------- | ----------- |
| `history` | Muestra el historial de comandos. |
| `find` | Busca archivos dentro del Filesystem. |
| `grep` | Busca texto dentro de archivos o filtra la salida de otro comando. |
| `man` | Muestra el manual del comando deseado. |
