## Introducción

En general, los administradores de sistemas interactuan con el sistema
 a traves de la CLI (Command Line Interface). Esto es asi por que las interfaces graficas suelen 
ser ineficientes. Por un lado, utilizan mayor espacio en disco y por otro suelen no permitir realizar
 la misma cantidad de acciones o personalizar las instrucciones como uno esperaria.
Los comandos son la forma que tenemos de pasarle instrucciones al sistema operativo (a traves de la CLI)
 para que este realice lo que necesitamos.
 Para esto es fundamental conocer los comandos y como se componen.

## Syntaxis

Los comandos en linux deben enunciarse de esta forma

Comando [opciones] [argumentos]

Nota: opciones y argumentos no son obligatorios

Ej: "chmod u+x archivo.sh"

Esto cambia los permisos del archivo para el usuario agregandole privilegios para ejecutar.

## Comandos de navegación

"pwd" = Print Working Directory, muestra en donde estámos parados dentro del Filesystem.

"cd" = Change Directory, nos permite cambiar de un directorio a otro

"ls" = List, enumera archivos y directorios

## Comandos de encendido y apagado

"shutdow" = Apaga el sistema de manera ordenada

"reboot" = Reinicia el sistema

"du" = Disk Usage
