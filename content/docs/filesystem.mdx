El filesystem de linux es jerarquico. En el nivel mas alto se encuentra lo que llamamos root representado por "/"
En Windows cada disco utiliza una letra como C:, D:, etc. En linux solo existe "/" y el resto de los directorios son subdirectorios de este.

/     Root solo contiene directorios, no archivos, los cuales se ubican en los subdirectorios.
/bin	Contiene binarios, es decir archivos ejecutables de las aplicaciones.
/dev	Contiene Devices o dispositivos que representan perifericos o hardware.
/etc	Contiene archivos de configuracion del sistema y usuarios, generalmente llamados servicios.
/home	Archivos de los usuarios. Cada usuario tendra su subdirectorio, a menos que se configure lo contrario.
/lib	Librerias del sistema.
/media  Punto de montaje de dispositivos extraibles como USB o DVDs.
/mnt	Punto de montaje para sistemas remotos.
/opt	Directorio para archivos de terceros (third party).
/proc	Es un filesystem virtual que contiene información de procesos y el kernel.
/root	Home del usuario root.
/run	Archivos temporales y variables del entorno temporales o volatiles
/sbin	Binarios del sistema.
/srv	Contiene información de los servicios.
/sys	Archivos con información del kernel.
/tmp	Contiene archivos temporales y de la sesion activa (en general se pierden al reiniciar).
/usr	Aplicaciones y librerias relacionadas al usuario.
/var	Archivos variables: Logs, Spools (colas).
