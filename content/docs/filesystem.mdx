El filesystem de Linux es jerárquico. En el nivel más alto se encuentra el **root**, representado por `/`.

En Windows cada disco utiliza una letra (`C:`, `D:`, etc.). En Linux solo existe `/` y el resto de los directorios son subdirectorios de este.

## Directorios principales

| Directorio | Descripción |
| ---------- | ----------- |
| `/` | Root. Por convención solo contiene directorios; los archivos se ubican en los subdirectorios. |
| `/bin` | Binarios, es decir, ejecutables de las aplicaciones. |
| `/dev` | Devices: dispositivos que representan periféricos o hardware. |
| `/etc` | Archivos de configuración del sistema y de los servicios. |
| `/home` | Archivos de los usuarios. Cada usuario tiene su subdirectorio, a menos que se configure lo contrario. |
| `/lib` | Librerías del sistema. |
| `/media` | Punto de montaje de dispositivos extraíbles, como USB o DVDs. |
| `/mnt` | Punto de montaje para sistemas de archivos montados manualmente (por ejemplo, remotos). |
| `/opt` | Software de terceros (third party). |
| `/proc` | Filesystem virtual con información de procesos y del kernel. |
| `/root` | Home del usuario root. |
| `/run` | Datos temporales y volátiles del sistema en ejecución. |
| `/sbin` | Binarios del sistema (administración). |
| `/srv` | Datos de los servicios. |
| `/sys` | Filesystem virtual con información del kernel y los dispositivos. |
| `/tmp` | Archivos temporales (en general se pierden al reiniciar). |
| `/usr` | Aplicaciones y librerías de usuario. |
| `/var` | Archivos variables: logs, spools (colas). |
